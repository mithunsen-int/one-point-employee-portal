# One-Point Employee Portal — Internal Transfer Journey

Next.js application implementing the Employee Internal Transfer Digital Journey (BRD-001 through BRD-007). Built via Specification-Driven Development — see `CLAUDE.md` for the operating rules and `.ai-context/` for the full spec/plan/task chain; this file stays operational only (setup, run, deploy), per `sdd-methodology.md` #22.

## Setup

```bash
npm install
```

## Run (development)

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Run (production)

```bash
npm run start
```

## Lint
