## Coverage Gaps
None identified — all 13 ACs (AC1–AC13) are covered by at least one task above. `T08` is infrastructure plumbing with no dedicated AC of its own — cited representatively against the spec's existing "MongoDB is the sole approved datastore" Non-Functional Constraint, the same "representative citation" pattern already used elsewhere in this project for foundational, non-AC-shaped tasks.

No endpoint currently calls `withAuthorization` (`T06`) — the only route in the codebase (`POST /auth/login`) is correctly excluded (it issues tokens; it isn't a protected endpoint). Every future protected route, in this spec or any other, must wrap itself with `withAuthorization(<action>, handler)` to actually satisfy `AC1`/`AC2` in practice — this is opt-in by construction, not enforced by a global gate, so `user-management-console.API06`'s exclusion is automatically satisfied by simply never wrapping it, with no special-case code needed.
