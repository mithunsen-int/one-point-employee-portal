Generate a plain prompt file for each workflow under .agent/workflows/ — this
project does not use slash commands. Each prompt file must cause the same
action its corresponding workflow describes, invoked by referencing the file
directly and stating the argument after "for," e.g. "@generate-plan.md for
<feature-slug>", instead of "/generate-plan <feature-slug>".

Requirements:

- Do not use slash-command YAML frontmatter (description/argument-hint) —
  that is slash-command-specific metadata with no equivalent need here;
  these are plain markdown files.
- Body must:
  1. Instruct reading .agent/workflows/<workflow-name>.md in full, then
     executing it exactly — Preconditions, then Steps in order, then Output,
     honoring every item in "Do not." No paraphrasing, no skipping a step.
  2. Explain how the prompt is invoked: reference the file directly and take
     whatever value follows "for" as the workflow's argument — <feature-slug>
     for every workflow except generate-spec.md, which takes the source BRD
     entry's own ID (<BRD-#>) instead, since it derives the feature-slug
     itself; or <feature-slug>.T0<n> for task-scoped workflows. If no value
     follows "for," stop and ask rather than guessing.
  3. Close with the same single-source-of-truth statement as before: the
     workflow file governs behavior, this prompt file must not duplicate its
     instructions from memory, so the two can't drift apart.
- Place the generated files under prompts/. This project does not use
  .claude/commands/ for these — do not create or leave files there, and do
  not register any of these as slash commands.
- Before generating a prompt file, confirm its corresponding
  .agent/workflows/<workflow-name>.md file actually exists. A prompt file
  must never be generated from a workflow file that doesn't exist yet —
  generate the others and flag the missing one instead of inventing a
  workflow to satisfy it.
- Update CLAUDE.md's artefact-chain table and any other slash-command
  references so the file stays accurate against what actually exists under
  prompts/.
